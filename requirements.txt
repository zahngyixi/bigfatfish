# ==================== 注意事项 ====================
# 1. Termux 环境需要先安装系统依赖:
#    pkg update && pkg upgrade
#    pkg install python python-pip
#    pkg install rust  # chromadb 编译依赖
#    pkg install ffmpeg  # 音频处理
#    pkg install espeak  # pyttsx3 备用 TTS
#    pkg install redis  # Redis 服务器
#
# 2. sherpa-onnx 模型需要单独下载到 models/sherpa-onnx/ 目录
#    推荐模型: sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23
#    下载链接: https://github.com/k2-fsa/sherpa-onnx/releases
#
# 3. ChromaDB 在 ARM64 上首次安装可能需要编译，耗时较长（约 5-10 分钟）
#
# 4. 如果某些包在 Termux 安装失败，可以尝试:
#    pip install --no-binary :all: <package_name>
#    或使用 --only-binary :all: 强制使用 wheel
